# Checkpoints do Flashinho

Use esta pasta para registrar marcos importantes do projeto quando uma etapa terminar ou antes de uma troca de chat relevante.

Formato sugerido:

`YYYY-MM-DD-HHMM-descricao.md`

Cada checkpoint deve conter apenas fatos necessários para reconstruir o estado:

- objetivo da etapa;
- estado confirmado;
- mudanças realizadas;
- testes e evidências;
- falhas e bloqueios;
- decisões novas;
- próxima ação.

Nunca incluir secrets, tokens, senhas, cookies ou credenciais.

O arquivo vivo continua sendo `FLASHINHO_STATE.md`; checkpoints são histórico imutável de marcos anteriores.
